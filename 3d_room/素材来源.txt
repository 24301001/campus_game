素材与许可证
========================================

1) assets/Soldier.glb —— 士兵角色
   来自 Adobe Mixamo 的 "Vanguard" 角色（含 Idle / Walk / Run 动画）。
   Mixamo 素材可供注册用户免费使用。

2) assets/ak47.glb + assets/arms_basecolor.webp + assets/arms_normal.webp —— 第一人称 AK-47
   来源：GitHub 仓库 cktang88/3d-fps（public/assets/models/fp/）
   许可：CC BY 4.0（已做尺寸与接入方式上的改动）
   该仓库注明：枪械动画 rig 模板来自 ccransh 在 Sketchfab 的
   "FPS AK-74m animations"；手套手臂模型来自 bumstrum / DJMaesen 在
   Sketchfab 的 "Fps arms"。

3) assets/zombie_real.glb + assets/zombie_tex/*.png —— 走廊里的丧尸（写实风格）
   作者：Rikindle3D
   来源：OpenGameArt.org 的 "Male City Zombie, Ready for use in Game Engines"
   许可：CC0 1.0 公共领域（可商用、可修改、无需署名）
   原始文件：InfectedCityMan.fbx（骨骼模型）+ 6 张 PBR 贴图
             （身体/衣服各一套 BaseColor / Normal / OcclusionRoughnessMetallic）
             + 11 个单独的动画 FBX（Idle、Idle2、Walk、Walking、Running、
             Zombie Attack 1~3、Reaction Hit、Dying、Scream）
   本项目做的处理：
   - 用 three.js r160 的 FBXLoader + GLTFExporter 在离线脚本里把模型和动画
     合成一个 GLB（assets/zombie_real.glb），动画挑用 8 段并改名：
     Idle / Walk / Run / Punch / Punch2 / HitReact / Death / Scream
   - 贴图转存为 assets/zombie_tex/ 下的 body_*.png、outfit_*.png，
     运行时再挂到材质上
   模型身高 1.79 米，正面朝 +Z。

3b) assets/zombie.glb —— 上一版卡通丧尸（Quaternius，CC0）
   文件保留作备份，现在游戏已经不再加载它。

3c) assets/giant_mutant.glb —— 「大块头」用的巨型变异体（写实风格）
   作者：eldritch-grim
   来源：OpenGameArt.org 的 "Giant Mutant"
   许可：CC0 1.0 公共领域（可商用、可修改、无需署名）
   原始文件：Giant Mutant.glb（作者直接提供的 GLB，自带贴图，
             含 Giant Run / idle / Right Punch / Left Punch /
             Jump Slam / Death 六段动画）
   本项目做的处理：
   - 它自带的静止姿势是「躺平」的，只有播动画时才站起来；
     所以量身高的时候先播一帧 idle，按蒙皮后的真实包围盒来量
     （直接量静止姿势会把它当成一条六米长的麻袋）
   - 正面朝向用「膝盖往哪边弯」判定（两腿膝盖都在髋—踝连线的 +Z 一侧），
     确认它本来就跟其他模型一样正面朝 +Z，不需要额外转
   - 统一归一化：脚底贴地、胯对齐原点、基准身高 1.79 米
     （游戏里大块头再放大到约 2.36 米）
   - Jump Slam 那段自带六米多的位移，一播整个人就飞出去，游戏里不用它

3d) assets/horror_game_monster.glb + assets/monster_tex/*.webp ——
   「扑食者」用的人形怪物（写实风格，血丝脓疮）
   作者：city-building-game-art
   来源：OpenGameArt.org 的 "3D Horror Game Monster"
   许可：CC0 1.0 公共领域（作者声明为 public domain，用于 Unity 项目）
   原始文件：Poses.zip（Idle / Walk / Run / Jump 四段动画 FBX）
             + Colors.zip（Green 配色那套 2K 的 Albedo / Normal /
               MetallicSmoothness 贴图）
   本项目做的处理：
   - 用离线脚本（tools/fbx2glb.mjs）把四段 FBX 合成一个 GLB
   - 贴图降到 1024 并转成 webp；MetallicSmoothness 转成 three.js 用的
     ORM 图（G 通道 = 粗糙度、B 通道 = 金属度）
   - 游戏里只用 Idle / Walk / Run 三段；Jump 那段整个人往地下扎
     （最低到 -1.87），播出来是钻地不是扑，所以不挂在任何动作上；
     它没有倒地动画，尸体由程序自己往前栽倒
