# 3D 房间（第一人称射击小演示）

像素校园里的「计算机中心」那一栋进去之后玩的东西：一间办公室 + 一条走廊 + 四间教室，
顶住 4 波丧尸（200 / 300 / 400 / 500）就通关。

## 怎么跑

双击 `启动.bat`，它会用 Python 起一个本地小服务器并打开浏览器（http://127.0.0.1:8123/）。

> ⚠️ 不要直接双击 `index.html`。页面用的是 ES module，必须走 HTTP，
> 否则模型和音效都读不出来。

没有 Python 的话到 python.org 装一个，安装第一步勾选 “Add Python to PATH”。

操作说明见 `怎么玩.txt`。

## 目录

| 路径 | 说明 |
|---|---|
| `main.js` | 全部游戏逻辑（约 21 万字节，单文件） |
| `index.html` | 页面骨架 + HUD + 开场遮罩 |
| `vendor/` | three.js r160 及官方示例里的 GLTFLoader / SkeletonUtils / meshopt 解码器 |
| `assets/` | 模型与音效（丧尸、巨型变异体、人形怪、枪械、贴图、ogg 音效） |
| `tools/` | 离线工具：FBX→GLB 转换、模型体检、贴图/朝向核验脚本 |
| `素材来源.txt` | 每个模型/音效的出处与许可证 |

## 三种敌人

- **普通丧尸 / 爆炸者**：同一套人形骨架，靠骨骼缩放和材质区分。
- **巨型变异体（大块头）**：另一套模型（eldritch-grim 的 Giant Mutant，CC0），
  2.36 米高，**只在走廊里活动，不会跟进房间**——想打它得自己走出去。
- **扑食者**：另一套模型（city-building-game-art 的 3D Horror Game Monster，CC0），
  会跳到玩家头上，被按住时开不了枪，得狂按空格甩开。
