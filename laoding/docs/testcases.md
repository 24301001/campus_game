## 七、阻断级缺陷排查

| 缺陷 | 状态 | 证据 |
|------|------|------|
| OCR 单字段校验 | 已规避 | `toolVerifyClaim` 要求学号+姓名双字段 |
| 云端挂掉卡死 | 已规避 | `toolMatchByImage` catch 降级；`toolOcrCard` 失败提示手输 |
| 越权回答 | 已规避 | `classify` refuse 分支 + `refuse_routes` 路由 |
| 持久化证件原图 | 已规避 | saveChat 置 src=null；入库只落学号姓名；cv_service 不落图 |
| 破坏单 HTML | 已规避 | 单文件，零第三方依赖 |
| 点位 ID 对不齐 | 已规避 | mapId 预留字段，合体仅替换数据源 |
