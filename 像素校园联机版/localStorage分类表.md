### ⚠️ 两条踩过的线，记在这儿

1. **`Authorization: Bearer `（空头）比不发更糟。** 老丁与学霸哥的服务端都是
   `startswith("bearer ")` 优先走 Bearer 支路，一个空 token 会把 cookie 那条路**挡死** ——
   没票时必须**整个头都不发**。`xueba-ge/web/app.js` 的流式 `/api/chat` 就栽过这一处。
2. **`logout()` 不能再 `document.cookie = "...=; max-age=0"`。** HttpOnly 的票 JS 删不掉，
   只能让服务端下一条 `Set-Cookie` 作废它 ⇒ 退登必须先喊 `/api/logout`，再 reload。
   学霸哥那边还有一条护栏：`/api/logout` 自己挨 401 时**不许**再触发 `logout()`，
   否则 logout → api → logout 死循环。

### 出口（登录窗删掉之后，"认不出票"要说出来）

三家服务 + 刷题平台 SPA 一律**不再弹自己的登录框**，改为向宿主报一声：

```
iframe → window.parent.postMessage({type:"pixelcampus:need-ticket", from:"xbg|ld|cmr|agent"})
地图   → mpEnsure(key) → /api/auth/exchange 补票 → 成功就把那个抽屉重载一次
                     ↳ 补不上且是刷题平台 ⇒ 落回地图 loginGate()
```

监听在 `像素校园_多人版.html` 的登录段末尾（源码 `_patch/unified_login.js`），
发送在 `campus_game/frontend/src/utils/hostAuth.js`（router guard 与 axios 401 两处）。
