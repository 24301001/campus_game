## 一、本文档解决什么

七份任务文档各自说清了"**我这一块是什么**"，但都没说：

1. **五个角色加一只猫，在地图上分别待在哪、什么时候出现**；
2. **玩家怎么和地图交互**（走、看、进门）；
3. **玩家怎么和角色 / 猫交互**（靠近、搭话、撸猫）；
4. **角色怎么和地图接**（角色要地图给什么、地图要角色给什么）。

一句话：**七块拼图怎么拼成一张能玩的校园。**

## 二、一张表：谁在地图上，落在哪

**五个角色 + 四只猫，各有各的落位。落位不是随便摆的，它由角色的功能载体决定。**

| 对象 | 常驻 / 刷新点 | 场景 | `roam` 移动性 | 出现时间 | 主动性 |
|---|---|---|---|---|---|
| **向导 · 小北** | 南门附近主路（出生点旁） | 室外 | `static`（不移动） | **常驻** | **不主动**——他不能像弹窗 |
| **学霸哥** | **逸夫一楼自习区** | 室内（逸夫一楼） | `shuttle`：教学楼 ↔ 图书馆 | 白天为主；中午去食堂 | 可主动（低预算，1 次/天） |
| **算法哥** | **计算机中心机房** | 室内（计算机中心） | `static`（机房/图书馆电脑区） | 下午与晚间 | 可主动（比赛/题单提醒） |
| **阿姨 · 丙** | **食堂窗口后** | 室内（食堂两层） | `static`（只在窗口之间挪） | **只在饭点** | **最活跃**——路过食堂偶遇 |
| **保安 · 老丁** | 全域巡逻路径点 | 室外 | `patrol` 多点巡逻 | 08:00–22:00 | **可被呼叫**——全图唯一 |
| **猫宠（4 只）** | 各自领地：食堂后门 / 图书馆台阶 / 明湖南岸影壁 / 思源楼草坪 | 室外 | `territory`（领地内游走） | 读作息，**晚上不出现** | 不主动搭话——**用动作表达** |

**三条落位原则**

| 原则 | 为什么 |
|---|---|
| **功能载体决定刷新点** | 学霸哥刷在自习区、算法哥刷在机房、阿姨刷在窗口后——**进门就能看见他，不用找** |
| **一个角色一个"家"** | 每个角色有唯一 `home`，玩家问"他在哪"能稳定回答 |
| **引导动线不重叠** | 向导在南门（新生第一站）、学霸哥在教学区、阿姨在食堂、算法哥在机房、保安在路上——**逛一圈能全部见到** |

## 三、玩家与地图的交互

### 3.1 三种基本操作

| 操作 | 输入 | 结果 |
|---|---|---|
| **移动** | `WASD` / 方向键（八向） | 角色按八向走，碰撞体挡人，走不进墙与水面 |
| **缩放** | 滚轮 / `+` `-`，上限 3x、下限 25% | 看全图与看细节两档需求都满足 |
| **交互** | `E` / 回车 / 点击附近对象 | 对**当前最近的可交互对象**发起交互（角色对话 / 猫 / 门 / 档口） |

### 3.2 相机与遮挡

- **相机跟随玩家**，达到世界边界时 `clamp`，不滑出世界；
- 所有对象（建筑、道具、角色、猫）按 **`baseY`（落地线）排序**——走在建筑后自然被遮挡，**不需要额外遮罩**。

### 3.3 场景切换（室外 ↔ 室内）

| 规则 | 内容 |
|---|---|
| 触发 | 走到门口 → 自动切换（不需要按键） |
| 门表 | **双向两条记录**，出门落点**外推一个身位**，防止来回弹 |
| 切换方式 | **硬切**——像素游戏没有"过场动画"，硬切就是对的 |
| 相机 | 进楼瞬间归位，`clamp` 上界换成室内尺寸 |
| 点位 | NPC 点位 ID 带**场景前缀**（`yifu1:reading_room` / `out:canteen`），引擎按前缀找场景 |

### 3.4 玩家能用地图做的三件事

1. **自己走**——从南门走到图书馆，一路有建筑、有树、有时间光影；
2. **叫别人走**——向导把镜头**飞过去 + 路径高亮**；保安**从别处走过来**（全图唯一 1 个"叫得动"）；
3. **看别人的痕迹**——有口碑的窗口高亮、失物点位标记、他人在某地留下的足迹。

## 四、玩家与角色的交互

### 4.1 基本动线（四个状态）

```
① 靠近        → ② 出现可交互提示 → ③ 对话（多轮） → ④ 走远结束
   距离 < 触发圈     头顶气泡 / 提示符        气泡逐句出        出圈即结束
```

| 状态 | 表现 | 说明 |
|---|---|---|
| 靠近 | 角色**转向玩家** | 最省事的"他注意到你了" |
| 提示 | 头顶冒提示符 + 一句招呼 | 招呼语来自 `persona` 配置，**不是通用"你好"** |
| 对话 | 气泡逐句出 + 角色切"说话"帧 | 支持多轮追问；答不了走 `unknown_line` 并**推给对的人** |
| 结束 | 角色回到待机（必须有待机动画） | 不做"再见"按钮，走远即结束 |

### 4.2 交互半径与"最近优先"

- 同时靠近两个对象时，**取距离最小的那个**；
- 对话中锁定对象，**不会中途切到别人**；
- 猫的交互半径**小于**角色——它是"你主动凑上去"，不是"它拦你"。

### 4.3 谁主动、谁不主动（必须写死的边界）

| 类型 | 谁 | 说明 |
|---|---|---|
| **不主动** | **向导 · 小北** | 他是"地图的出口"，一主动就成了**地图在弹窗** |
| **可主动（低预算）** | 学霸哥 / 算法哥 | 每天 ≤ 1~2 次，走"偶遇"通道 |
| **最活跃** | 阿姨 · 丙 | 只在饭点出现在食堂，路过即偶遇 |
| **叫得动** | **保安 · 老丁**（全图唯一） | 点"呼叫"→ 他自己沿路走过来（08:00–22:00） |
| **不搭话** | 猫宠 | 只有动作：跑 / 退 / 让摸 / 跟着走 |

> **主动提醒一律不是推送**：它必须由「**地图 + 时间 + 记忆**」三者交叉才算得出来，载体是**"路上碰见跟你说一句"**。

## 五、角色与地图的接口（谁要谁什么）

| 方向 | 内容 |
|---|---|
| **角色 → 地图**（要地图给） | `focus(placeId)` 镜头飞行、`highlight(ids)` 高亮、`findPath(from,to)` 取路、`getPlace/listPlaces` 查点、`setLayer` 切图层、`nearestWalkable` 落点吸附 |
| **地图 → 角色**（要角色给） | 每个 `agents/*.json` 的 `home` / `schedule[].at` / `roam.waypoints`（**点位 ID，室内带场景前缀**） |
| **玩家 → 双方** | 位置（地图）、对话与记忆（角色） |
| **唯一的数据约定** | **点位 ID 必须能与地图节点对齐**——`out:` 为室外、`<场景>:` 为室内 |

> **接口约定 ≠ 实现依赖**：每个角色独立开发时**不依赖别人的代码**，合体时靠上面这张表对接。

## 六、玩家与猫的交互

| 档位 | 玩家体验到的 | 对应动作 |
|---|---|---|
| 陌生 → 眼熟 | 它躲你 | 靠近即跑 / 走近即退 |
| 熟 | **不让摸** | 能走到跟前，按摸 → 退开 |
| 亲近 | **让摸** | 蹭你脚边 |
| 很亲 | **主动跟** | 跟走一段路 |
| 最亲（罕见） | **在你常出现的地方等你** | 老地方蹲守 |

| 规则 | 内容 |
|---|---|
| 触发 | 走近（120px 内）按 `G` 弹**就地动作轮盘**（摸 / 喂 / 叫它 / 逗它）——**不开背包、不选道具** |
| 频率 | 同一只猫**每天一次**冷却（防刷） |
| 反馈 | **只有动作，没有数字**——不做好感度进度条 |
| 图鉴 | **认识一只点亮一格**，四格互不覆盖 |
| 领地 | 猫不出自己的 `radius`：不进屋、不穿墙 |

> ⚠️ **轮盘不是"菜单"**（2026-10-09 定性）：它是一个就地弹的动作盘，
> **只有动作**——没有道具、没有数量、没有页签、没有好感数字。
> 下面那条「只有动作，没有数字」**一个字不改**。
> ⚠️ 猫**全天都在**（作息只换地方，不做"晚上消失"）。

## 七、合体后最容易出问题的四处（提前写死）

| # | 风险 | 处理 |
|---|---|---|
| 1 | **两个对象的交互圈重叠** | 取最近 + 对话期间锁定；猫的半径小于角色 |
| 2 | **室内点位在向导图谱里不存在** | 图谱 `places` **必须加室内节点**，否则问"逸夫楼自习室在哪"带不了路 |
| 3 | **遮挡排序在室内失效** | 室内家具与角色**沿用同一套 `baseY` 排序与 `ax/ay` 锚点**——不新定一套 |
| 4 | **主动性叠加成打扰** | 每人每天主动 ≤ 1~2 次、全局 ≤ 6 次；冲突时按 `importance` 只发 top-1，其余进信箱 |

## 八、验收（合体层）

| # | 验什么 | 通过标准 |
|---|---|---|
| 1 | **五个角色都能按表找到** | 不看提示，按"功能载体"就能猜到在哪并找到 |
| 2 | **进得去出得来** | 三栋室内可进，出门落在门外侧，不来回弹 |
| 3 | **交互不打架** | 两个对象重叠时取最近；对话中不串台 |
| 4 | **叫得动** | 只有老丁响应呼叫且能沿路走过来；其余角色不响应 |
| 5 | **不打扰** | 主动性每日上限生效，向导一次都不主动 |
| 6 | **猫不越界** | 长时间观察，猫始终在领地内 |
| 7 | **向导能带室内路** | 问室内点位，图谱命中且路径可高亮 |
| 8 | **仍然单文件零依赖** | 合体后仍是一个 HTML、零外部请求 |
